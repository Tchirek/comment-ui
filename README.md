# 💬 Sodesu for NormalPics

A public AGPL fork of [Sodesu v0.5.2](https://github.com/BeiyanYunyi/sodesu), reshaped into a focused iframe comment UI for NormalPics and its Cloudflare Worker/D1 comment API.

## Inspiration

Sodesu already had the right small, nimble feeling. NormalPics needed that spirit in a narrower form: Markdown comments, replies, likes, and a quiet `postMessage` bridge, loaded only when the gallery asks for it.

The original source, copyright notices, and AGPL license are kept. The NormalPics integration lives in `embed/`, with notes in `MODIFICATIONS.md` and `INTEGRATION.md`.
